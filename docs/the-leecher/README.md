# THE LEECHER — draaiplanning

Documentatiemap voor de herbouw van de draaiplanning-template (Google Sheets + Apps Script).

**Begin bij [`00-HANDOFF.md`](00-HANDOFF.md)** — dat is de overdrachtsprompt. Plak dat bestand
als eerste bericht in een nieuwe AI-sessie en het werk gaat verder waar het gebleven is.

| Bestand | Inhoud |
|---|---|
| `00-HANDOFF.md` | overdrachtsprompt: rol, status, wat er gebouwd moet worden |
| `01-opdracht.md` | de definitieve opdracht, letterlijk |
| `02-analyse-bestaand-systeem.md` | hoe het oude Luza-systeem (generator v3.1) werkt |
| `03-projectdata-the-leecher.md` | dagen, scènes, tijden, cast, locaties |
| `04-shotlist.md` | 15 scènes, 50 shots, met zoomkolom |
| `05-ontwerp-nieuwe-template.md` | het technische ontwerp dat gebouwd moet worden |
| `06-besluiten.md` | alle genomen besluiten + de 2 resterende gegevens |
| `bronnen/` | ruwe uitlezingen van de PDF's, de XLSX-tabbladen en de shotlist |

De Apps Script-code v3.1 van het oude systeem staat hier niet in — die wordt vervangen.
`02-analyse-bestaand-systeem.md` bevat alle mechanismen, formules en valkuilen eruit.
